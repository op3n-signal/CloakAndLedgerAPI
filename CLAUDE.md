## High-Level Architecture

EncompassAPI is an **orchestration service for automated mortgage disclosure management**, integrating Encompass (Ellie Mae's lending platform) with Salesforce, DocuSign, and AWS services.

### Solution Structure

- **EncompassAPI**: Main ASP.NET Core 8.0 Web API
- **EncompassAPITests**: xUnit test project with FluentAssertions
- **TokenGenerator**: CLI tool for generating signed/encrypted JWT tokens
- **Shared**: Common utilities (AWS Secrets Manager integration, constants)
- **TokenRotator**: Python-based scheduled token rotation (Dockerfile + cron)

### Layered Architecture

```
Controllers → Middleware → AppLayer Services → Service Layer → Repository Layer → Data Sources
```

**Controllers** (`DisclosuresController`, `DocumentsController`, etc.)
- REST endpoints that return 202 Accepted for async processing
- Fire-and-forget pattern using `Task.Run` with `IServiceScopeFactory`

**Middleware Layer**
- `EncompassMiddleware`: Extracts `x-e-Token` header and stores in HttpContext
- `EncompassTokenHandler`: HTTP message handler that adds Bearer token to downstream requests

**AppLayer Services** (Business Logic)
- `DisclosuresServiceV5`: Main orchestrator for disclosure workflow
- `DocumentService`: Document processing and management
- `StorageService`: AWS S3 operations
- `MappingAppService`: AutoMapper-based data transformations

**Service Layer** (Infrastructure & Integration)
- External integrations: `DocsService` (Encompass), `SalesforceService`, `DocusignService`, `eFolderService`
- AWS services: `S3Service`, `AWSSecretService`, `DataService` (MySQL), DynamoDB context
- `HttpService`: Flurl-based HTTP client wrapper

**Repository Layer**
- Dapper-based data access with MySqlConnector
- `CandidDataRepo`, `DisclosureDataRepo`, `DataRepo`, `TokenRepo`

### Authentication Flow

**Dual-Token System:**

1. **JWT Bearer Token**: Validates API caller identity
   - Generated by TokenGenerator CLI tool
   - Uses PBKDF2 key derivation with salt from AWS Secrets Manager
   - Both signed (HMAC-SHA256) and encrypted (AES-256)
   - Must include "Basic" role to access protected endpoints

2. **x-e-Token Header**: Encompass API access token
   - Passed through from client in request header
   - Extracted by `EncompassMiddleware` and stored in HttpContext
   - Added to downstream Encompass API calls via `EncompassTokenHandler`

**Token Generation Process:**
```bash
cd TokenGenerator
dotnet run -- <salt> <signing-key> <encryption-key> <username> <days-to-live>
```
Keys are derived from salts using PBKDF2 with SHA-512 (see `SecurityKeysBuilder.cs`).

### HTTP Client Configuration

The solution uses **named HttpClient instances** with different message handlers:

- **EncompassClient**: Uses `EncompassTokenHandler` to add Bearer token from HttpContext
- **DefaultClient**: Standard HTTP client without custom handlers
- `IEncompassHttpService` and `IDefaultHttpService` provide typed access

Registered in `Program.cs`:
```csharp
builder.Services.AddHttpClient<IHttpService, HttpService>("EncompassClient")
       .AddHttpMessageHandler<EncompassTokenHandler>();
```

### Service Versioning Pattern

Multiple versions of `DisclosuresService` exist (V2-V5), indicating iterative improvements. **Always use the highest version** (`DisclosuresServiceV5`) unless maintaining backward compatibility.

### Data Flow: Disclosure Retrieval

1. Client sends POST to `/api/disclosures/Retrieve` with JWT + `x-e-Token` header
2. JWT validated via Bearer authentication
3. `EncompassMiddleware` extracts and stores `x-e-Token`
4. Controller returns 202 Accepted immediately
5. Background task orchestrates via `DisclosuresServiceV5`:
   - Retrieves disclosure tracking from Salesforce
   - Fetches loan data from Encompass API
   - Manages DocuSign envelope creation and signing
   - Stores documents in S3
   - Tracks status in DynamoDB
   - Updates audit logs

### Configuration Management

Uses **Options pattern** with type-safe configuration classes:
- `AWSConfig`, `EncompassConfig`, `SalesforceConfig`, `DocusignConfig`
- Injected via `IOptionsSnapshot<T>` for runtime updates
- Sensitive values fetched from AWS Secrets Manager (see `Shared/SecretService.cs`)

### Error Handling Pattern

Services return `ProcessResult<T>` wrapper class that encapsulates:
- Success/failure state
- Typed result data
- Error messages

### Key Technologies

- **.NET 8.0** with nullable reference types and implicit usings
- **Dapper** for lightweight ORM with MySqlConnector
- **AutoMapper** for object-to-object mapping
- **Flurl** for fluent HTTP client operations
- **AWS SDKs**: DynamoDB, S3, Secrets Manager, CloudWatch logging
- **LiteDB** for embedded NoSQL operations
- **PdfSharpCore** for PDF manipulation
- **xUnit** + **FluentAssertions** for testing

### Data Storage

- **MySQL**: Org credentials, configuration, token storage
- **DynamoDB**: Disclosure tracking, queue management, audit logs
- **S3**: Document storage (PDFs, generated files)
- **LiteDB**: Local embedded storage for temporary data
